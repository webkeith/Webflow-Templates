3. Calibrate interactions from a real Webflow copy

Webflow doesn't document how interactions are stored on the clipboard. In the Designer, select any element that has a classic Mouse hover interaction set on its class (and, ideally, a combo class), press Cmd/Ctrl + C, then click the box below and press Cmd/Ctrl + V. The library compares Webflow's real data with what it generates and adapts future copies.
